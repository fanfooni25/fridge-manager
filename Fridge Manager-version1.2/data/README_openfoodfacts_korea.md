# Open Food Facts 韩国筛选数据

来源：用户下载的 Open Food Facts 搜索导出文件 `openfoodfacts_export.csv`（2026-10-18），合并到原有韩国市场精简数据。

筛选：`countries_tags` 包含 `en:south-korea`，且条码为 8–18 位数字；按条码去重。当前共 3,369 条唯一条码。相较上一份本地数据，新导出新增 4 条有效条码记录；合并时保留本地已有非空字段，仅用新导出补齐空字段。

精简字段：条码、名称（优先韩文，其次英文、中文、日文，再按主要语言回退）、品牌、分类、规格、份量，以及每 100g/100ml 热量和每 100g 营养值。当前 3,113 条有名称，356 条有每 100g 热量，13 条有每 100ml 热量；原始资料未提供的字段为空。
