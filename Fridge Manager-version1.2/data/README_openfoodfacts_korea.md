# Open Food Facts 韩国筛选数据

来源：用户下载的 Open Food Facts 高级搜索导出文件 `openfoodfacts_export (1).csv`（2026-10-15）。

筛选：`countries_tags` 包含 `en:south-korea`；按条码去重。导出 3,365 条唯一条码。

精简字段：条码、名称（优先韩文，其次英文，再按主要语言回退）、品牌、分类、规格、份量、每 100g 热量与营养值，以及每 100ml 热量。原数据缺失的字段保持为空；本批数据中只有 3,110 条有名称、347 条有每 100g 热量。

数据来自 Open Food Facts。若公开再分发或提供基于此数据的数据库，请注明来源并遵守 ODbL 许可（署名、相同方式共享）。数据本身由用户贡献，可能不完整或不准确。
